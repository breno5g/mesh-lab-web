# mesh-lab: páginas

Páginas de estudo de redes ponto a ponto, feitas para rodar direto no navegador.

- [Chat mesh](https://breno5g.github.io/mesh-lab-web/chat.html): chat em grupo entre navegadores, cifrado de ponta a ponta.
- [WebRTC na mão](https://breno5g.github.io/mesh-lab-web/webrtc.html): conecta dois navegadores copiando e colando a oferta e a resposta.

A criptografia do chat serve para estudo e não foi auditada.
